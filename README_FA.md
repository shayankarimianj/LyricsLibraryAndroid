# پروژه اندروید Lyrics Library

این پروژه یک پیاده‌سازی مستقل اندروید از کتابخانه متن آهنگ ویندوز است. فایل اصلی `lyrics_app.py` تغییر داده نشده است.

## امکانات پیاده‌سازی‌شده
- افزودن، ویرایش و حذف آهنگ
- ذخیره عنوان، متن، دستگاه و گام در SQLite محلی
- جستجو در عنوان، متن، دستگاه و گام با نرمال‌سازی حروف فارسی/عربی
- جابه‌جایی ترتیب آهنگ‌ها با لمس طولانی و کشیدن (وقتی جستجو خالی است)
- ذخیره دائمی ترتیب پس از جابه‌جایی و بازیابی آن در اجرای بعدی
- رنگ‌بندی تگ‌های دستگاه مطابق مقادیر تعریف‌شده در نسخه ویندوز
- تغییر اندازه و انتخاب خانواده فونت متن؛ تنظیمات در دستگاه ذخیره می‌شوند
- حداقل Android 8.0 (API 26)

## ساخت APK در Android Studio
1. نصب Android Studio و Android SDK (API 35).
2. باز کردن پوشه `LyricsLibraryAndroid` به‌عنوان پروژه.
3. صبر کردن تا Gradle وابستگی RecyclerView را دریافت کند.
4. از منوی **Build > Build APK(s)** استفاده کنید.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکته درباره APK
محیطی که این پروژه در آن تولید شده، Android SDK/Gradle و دسترسی شبکه برای دریافت ابزارهای ساخت ندارد؛ بنابراین APK قابل نصب را از این محیط نتوانستم کامپایل و آزمایش کنم. این بسته سورس مستقل و فایل‌های ساخت لازم برای Android Studio را دارد. قبل از انتشار یا استفاده روزمره، پروژه را در Android Studio بسازید و روی دستگاه واقعی آزمایش کنید.

## تفاوت‌ها و محدودیت‌های شناخته‌شده
- رابط کاربری برای صفحه موبایل بازچینی شده؛ ظاهر دسکتاپ ویندوز عیناً کپی نشده است.
- انتخاب فونت از خانواده‌های فونت عمومی اندروید است؛ فونت‌های سفارشی ویندوز خودکار منتقل نمی‌شوند.
- داده‌های نسخه ویندوز به صورت خودکار از فایل `lyrics.db` ویندوز وارد نمی‌شوند؛ برای انتقال داده‌ها باید فایل پایگاه داده را جداگانه تبدیل/وارد کرد.
- برای جلوگیری از تغییر ترتیب ناخواسته در نتایج فیلترشده، Drag & Drop فقط وقتی فعال است که کادر جستجو خالی باشد.


## ساخت APK بدون نصب Android Studio (با GitHub Actions)
این پروژه یک workflow ابری دارد که در GitHub اجرا می‌شود و APK را به‌عنوان Artifact تحویل می‌دهد؛ نیازی نیست Android Studio روی رایانه‌ات نصب باشد.

1. وارد GitHub شو و یک repository جدید بساز.
2. فایل ZIP پروژه را روی رایانه استخراج کن.
3. محتویات پوشه `LyricsLibraryAndroid` (از جمله پوشه مخفی `.github`) را در repository بارگذاری کن. مطمئن شو فایل `settings.gradle` در ریشه repository باشد.
4. در GitHub به تب **Actions** برو و workflow با نام **Build Android APK** را انتخاب کن.
5. روی **Run workflow** بزن و صبر کن تا اجرا سبز و موفق شود.
6. در صفحه اجرای workflow، پایین بخش **Artifacts**، فایل `LyricsLibrary-debug-apk` را دانلود و از ZIP خارج کن؛ داخل آن `app-debug.apk` است.
7. فایل APK را به گوشی بفرست و نصب کن. ممکن است لازم باشد اجازه نصب برنامه از همان منبع را در تنظیمات اندروید فعال کنی.

توجه: این روش به حساب GitHub و اتصال اینترنت نیاز دارد. APK تولیدشده نسخه debug است و پیش از استفاده نهایی باید روی گوشی واقعی آزمایش شود.
